# 🛠️ Retro Service - Backend

**Retro Service** is a location-based mechanic booking platform that allows users to book vehicle repair services, chat or video-call mechanics, and purchase auto parts. This is the backend API built using **Node.js**, **Express**, **MongoDB**, and JWT-based authentication.

---

## 📦 Features

- 🔐 JWT Authentication (Login/Register)
- 📍 Mechanic Search by Location & Wage
- 🧰 Auto Parts Store (CRUD APIs)
- 📅 Booking Management
- 📷 Image Upload & Firebase Storage
- 💬 User-Mechanic Chat and Video Integration (WebRTC)
- 👤 Role-based Access (User/Mechanic/Admin)
- 📊 Dashboard APIs

---

## 🧱 Tech Stack

- **Node.js**
- **Express.js**
- **MongoDB + Mongoose**
- **Firebase (for image storage)**
- **Socket.IO or WebRTC (for live chat/video)**
- **JWT for secure auth**
- **Multer** for file upload
